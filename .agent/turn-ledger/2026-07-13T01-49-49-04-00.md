## Source-backed finding

```txt
mousemove(event)
  -> updates this.pointer and this.mouse

click(event)
  -> event coordinates discarded
  -> clickHotspot()
  -> pick() reads cached this.pointer
  -> raycast uses current camera object
```

Consequences:

```txt
first click before mousemove can raycast at 0,0
touch/stylus click can use default or stale coordinates
quick click can combine a new pointer sample with the previous RAF camera pose
hover state is not cleared on pointer leave
canvas and side-panel inspection paths do not share one command/result contract
```
